一、演算法介紹 (什麼是 GAN？)

生成對抗網路（GAN）由 Ian Goodfellow 於 2014 年提出。它主要為了解決「資料不足」或「缺乏創造力」的問題，能夠從無到有生成極度逼真的影像、聲音或文字。它的核心思想是讓生成器與判別器進行零和博弈，在不斷對抗的過程中共同進化，最終讓 AI 學會生成逼真的數據。

生成器 (Generator, \(G\))

輸入： 隨機雜訊向量 \(z\)
輸出： 生成的假數據 \(G(z)\)
目標： 極力模仿真實數據的分佈，努力產出能讓判別器誤以為是真實數據的假圖，希望極小化判別器辨識出假圖的機率

判別器 (Discriminator, \(D\))

輸入： 真實數據 \(x\) 或假數據 \(G(z)\)
輸出： 一個 0 到 1 之間的機率值（1代表真，0代表假）
目標： 盡可能準確地區分真實數據和生成器產生的假數據，希望極大化自己的判別準確率

📐 數學原理：Min-Max Game (極小極大化博弈)

GAN 的訓練過程可以用一個目標函數 \(V(D, G)\) 來表示，這是一個 Binary Cross Entropy (二元交叉熵) 的變體：

\[ \min_G \max_D V(D, G) = \mathbb{E}_{x \sim p_{data}(x)}[\log D(x)] + \mathbb{E}_{z \sim p_z(z)}[\log(1 - D(G(z)))] \]
  • 判別器 \(D\) 的視角 (\(\max_D\))： 努力讓公式的值最大化。對於真實數據 \(x\)，希望 \(D(x)\) 越接近 1 越好（此時 \(\log(1)=0\) 最大）；對於假數據 \(G(z)\)，希望 \(D(G(z))\) 越接近 0 越好（此時 \(\log(1-0)=0\) 最大）。
  • 生成器 \(G\) 的視角 (\(\min_G\))： 努力讓公式的值最小化。因為它控制不了真實資料項，它只能想辦法讓自己生成的假數據 \(G(z)\) 騙過判別器，也就是希望 \(D(G(z))\) 越接近 1 越好（此時 \(\log(1-1) \to -\infty\)，達到極小值）。

項目二、AI 輔助學習紀錄

在實作本專案的過程中，我利用了 AI 助手來協助釐清艱澀的演算法概念，並指導我如何將 Python 模型轉換為網頁視覺化。

問題 AI 回答重點摘要 如何幫助我理解
為什麼生成器一開始必須輸入「隨機雜訊」，而不是空白圖片？ 如果輸入固定圖片，生成器只會產出單一結果。隨機雜訊能提供多樣性，讓模型學習將不同的雜訊映射成具有不同特徵（如筆跡、粗細）的數字 解開了對無中生有的疑惑，雜訊是確保模型能生成多樣化、不重複結果的關鍵
判別器到底是如何判斷一張圖片是真是假？ 判別器本質上是一個二元分類器，它會分析圖片的紋理、邊緣等特徵，藉由同時觀察真圖與假圖，不斷修正神經網路權重來找出兩者在像素特徵上的差異 讓我了解判別器並不是單純死背整張圖片的樣子，而是學習辨識細微的高維度特徵
為什麼訓練時 D loss 和 G loss 加起來不等於 1？ AI 解釋它們不是機率相加，而是分別透過交叉熵計算出的誤差值。兩者目標不同，只有在達到納許均衡時，Loss 皆會收斂在特定的數值 (-ln(0.5) 約等於 0.693)。 讓我釐清了 GAN 訓練時評估指標的真正意義，不再誤以為兩者是零和機率。

項目三、查證與修正

🔍 AI 生成內容的查證過程

在學習過程中，我發現 AI 提供的一些資訊需要進一步查證與修正：

  • Loss 函數的解釋：最初 AI 簡單地說「D loss 是判別真假的誤差，G loss 是欺騙的誤差」，但這過於簡化。我查閱了 Ian Goodfellow 的原始論文與 PyTorch 官方文件，才確認這是基於 Binary Cross Entropy 計算的結果，並修正了網頁中關於 Loss 的小知識說明。
  • 程式碼的維度問題：AI 給的 cGAN 核心架構中，將圖片攤平與還原的 view 函式維度有時寫死為特定批次大小。我將其修正為 img.view(img.size(0), -1) 與 img.view(img.size(0), 1, 28, 28)，以支援動態批次訓練。
  • 資源消耗的提醒：AI 較少主動提醒 GAN 訓練對於運算資源的巨大消耗。實際測試後我發現原本的參數會導致網頁卡頓，因此我調整了視覺化腳本中的動畫頻率與取樣數，確保互動體驗的流暢。

項目四、實作範例與視覺化說明

GAN 核心架構示意圖

4.0 實作範例：條件式 GAN (cGAN) 核心架構

import torch
import torch.nn as nn

# ==========================================
# 定義生成器 (Generator)
# 任務：接收「隨機雜訊」與「指定數字標籤」，生成對應的假圖片
# ==========================================
class Generator(nn.Module):
    def __init__(self, latent_dim, num_classes=10):
        super(Generator, self).__init__()
        self.latent_dim = latent_dim
        
        # 【關鍵設計】將數字標籤 (0-9) 轉換為特徵向量，讓神經網路看得懂條件
        self.label_embedding = nn.Embedding(num_classes, num_classes)
        
        # 建立神經網路層 (輸入維度 = 雜訊長度 + 標籤長度)
        self.model = nn.Sequential(
            nn.Linear(latent_dim + num_classes, 128),
            nn.LeakyReLU(0.2, inplace=True),
            nn.Linear(128, 256),
            nn.BatchNorm1d(256),
            nn.LeakyReLU(0.2, inplace=True),
            nn.Linear(256, 512),
            nn.BatchNorm1d(512),
            nn.LeakyReLU(0.2, inplace=True),
            nn.Linear(512, 784), # 輸出 784 維 (對應 28x28 的圖片像素)
            nn.Tanh()            # 使用 Tanh 將輸出顏色限縮在 [-1, 1] 之間
        )

    def forward(self, noise, labels):
        # 1. 取得指定數字的標籤特徵
        c = self.label_embedding(labels)
        # 2. 將「隨機雜訊」與「標籤特徵」串接在一起作為輸入
        x = torch.cat([noise, c], 1)
        # 3. 透過神經網路生成圖片
        img = self.model(x)
        # 4. 將一維的 784 轉換為 28x28 的二維圖片格式
        img = img.view(img.size(0), 1, 28, 28)
        return img

# ==========================================
# 定義判別器 (Discriminator)
# 任務：接收圖片與標籤，判斷這張圖片是否為「真實的」該數字
# ==========================================
class Discriminator(nn.Module):
    def __init__(self, num_classes=10):
        super(Discriminator, self).__init__()
        
        # 同樣需要將數字標籤轉換為特徵向量
        self.label_embedding = nn.Embedding(num_classes, num_classes)
        
        # 建立神經網路層 (輸入維度 = 圖片像素 784 + 標籤長度)
        self.model = nn.Sequential(
            nn.Linear(784 + num_classes, 512),
            nn.LeakyReLU(0.2, inplace=True),
            nn.Linear(512, 256),
            nn.LeakyReLU(0.2, inplace=True),
            nn.Linear(256, 1),
            nn.Sigmoid() # 使用 Sigmoid 輸出 0~1 的機率值 (1代表真，0代表假)
        )

    def forward(self, img, labels):
        # 1. 將 28x28 的圖片攤平為一維陣列 (784)
        img_flat = img.view(img.size(0), -1)
        # 2. 取得指定數字的標籤特徵
        c = self.label_embedding(labels)
        # 3. 將「圖片」與「標籤」串接在一起作為輸入
        x = torch.cat([img_flat, c], 1)
        # 4. 判斷這張圖片在該標籤下的真實機率
        validity = self.model(x)
        return validity

項目五、應用案例與未來潛力

在「AI 導論」的範疇中，生成對抗網路 (GAN) 無疑是近年來最具突破性的技術之一。以下針對 GAN 模型進行優劣勢評估與產業應用分析：

✨ 模型優勢 (Advantages)

  • 不需依賴複雜的數學推論：GAN 讓生成器與判別器互相對抗，直接從樣本學習資料分佈，避開了傳統繁瑣的機率計算。
  • 生成品質極高：與早期的生成模型 (如 VAE) 相比，GAN 生成的圖像邊緣更銳利、細節更清晰、整體更逼真。
  • 設計靈活度高：可以輕易擴展，例如加入條件成為 cGAN (控制生成結果)，或是 CycleGAN (不需要配對資料即可進行風格轉換)。

⚠️ 劣勢與挑戰 (Challenges)

  • 訓練極度不穩定：生成器與判別器必須保持動態平衡。如果判別器太強，生成器無法學習；反之亦然。容易發生「梯度消失」無法收斂。
  • 模式崩潰 (Mode Collapse)：模型可能會偷懶，發現生成某幾張特定的圖片最容易騙過判別器，導致生成的結果缺乏多樣性 (只會畫同一種圖)。
  • 評估困難：目前沒有一個絕對客觀且完美的數學指標，能準確評估生成的圖片到底有多真實。

🚀 未來潛力與商業應用

雖然近期擴散模型 (Diffusion Models, 如 Midjourney, Stable Diffusion) 佔據了文字生圖的熱門版面，但在許多即時運算與特定領域中，GAN 依然具有無可取代的商業價值：

1. 醫療影像擴增與隱私保護
在醫療領域，罕見疾病的真實影像極度缺乏。GAN 可以用來生成高品質的合成病理切片或 X 光片，幫助訓練更準確的 AI 診斷模型。同時因為是生成的圖片，也完美避開了真實病患的隱私與個資問題。
2. 電商虛擬試穿與商品生成
服飾品牌可利用 Image-to-Image GAN 進行虛擬模特兒換衣，或是讓設計師只要畫出衣服草圖，就能一鍵生成真實材質的商品照片，大幅降低商業拍攝與設計打樣的成本。
3. 遊戲與電影產業素材生成
開發團隊可利用 GAN 將低畫質的老舊材質「超解析化 (Super Resolution)」，或是快速生成無數種不同的 NPC 臉孔、地貌與環境貼圖。GAN 生成速度極快，非常適合遊戲內的即時運算。
4. 數位孿生與影音修復
將黑白老電影自動上色、修復受損影片，甚至是深度偽造 (Deepfake) 技術的基礎。許多新聞台與企業也開始利用 GAN 生成虛擬主播或名人的數位替身，進行 24 小時無間斷的影音播報。

項目六、學習反思

  • AI 對學習的幫助：在實作這次期末專案時，AI 不僅幫我把艱澀的數學公式（Min-Max Game）轉化為白話文，更協助我利用前端 Canvas 技術，將原本只能在終端機裡看的訓練過程，變成可以讓使用者直接互動、動態呈現的網頁，大幅提升了專案的完整度。
  • 反思 AI 回答的限制與缺點：AI 為了讓回答淺顯易懂，常用許多簡化與比喻，但這同時會把一些關鍵資訊給過濾掉
  • 總結學會的內容：在理論層次，我不再只是死背生成器與判別器的對抗，而是深入探討了背後的數學根基：從二元交叉熵到納許均衡，徹底理解了模型在多維度空間中如何尋找最佳解。在實作層次，我掌握了條件式 GAN (cGAN) 的核心架構，理解如何透過 nn.Embedding 將抽象的標籤轉換為特徵向量，讓模型能夠聽懂指令生成特定數字。這不僅拓展了我的技術視野，也讓我更有自信面對未來複雜的 AI 變化與應用開發。
