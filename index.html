Generative Adversarial Network 介紹

1. 什麼是 GAN？

生成對抗網路（GAN）由 Ian Goodfellow 於 2014 年提出。它的核心思想是讓兩個神經網路互相博弈、共同進化。不需要人類給予明確的規則，AI 就能在對抗中學會如何生成逼真的數據（如圖像、音訊）。

生成器 (Generator)

負責接收隨機雜訊，並嘗試將其轉換為有意義的數據。目標是「騙過」判別器。

判別器 (Discriminator)

負責接收真實數據與生成器的假數據，並判定數據的真偽。目標是「揪出」所有生成的贗品。

2. 實作範例 (PyTorch)

以下是一個基於 PyTorch 的簡單 GAN 架構示範，展示了生成器與判別器的基礎模型定義：

import torch
import torch.nn as nn

# 定義生成器 (Generator)
class Generator(nn.Module):
    def __init__(self, latent_dim):
        super(Generator, self).__init__()
        self.model = nn.Sequential(
            nn.Linear(latent_dim, 128),
            nn.LeakyReLU(0.2),
            nn.Linear(128, 256),
            nn.BatchNorm1d(256),
            nn.LeakyReLU(0.2),
            nn.Linear(256, 784),
            nn.Tanh() # 輸出範圍至 [-1, 1]
        )

    def forward(self, z):
        return self.model(z)

# 定義判別器 (Discriminator)
class Discriminator(nn.Module):
    def __init__(self):
        super(Discriminator, self).__init__()
        self.model = nn.Sequential(
            nn.Linear(784, 256),
            nn.LeakyReLU(0.2),
            nn.Linear(256, 128),
            nn.LeakyReLU(0.2),
            nn.Linear(128, 1),
            nn.Sigmoid() # 輸出為真偽的機率值 [0, 1]
        )

    def forward(self, img):
        return self.model(img)
